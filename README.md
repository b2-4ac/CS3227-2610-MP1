# Study Tracker

Study Tracker is a JavaFX desktop application that helps students record focused
study time by subject. It supports starting, pausing, resuming, and saving study
sessions; reviewing session history; and viewing active-time statistics for selected
date ranges.

Paused time is excluded from recorded study time. Sessions are stored as active
intervals, so statistics correctly account for breaks and study that continues past
midnight.
